## The company

Willis Property Services helps apartment communities, property managers, and local residents with:

- Drywall repairs
- Painting
- Caulking
- Flooring
- Tile
- Concrete pouring and repair
- Furniture assembly
- Door repairs
- Appliance placement
- Property cleanouts
- General property maintenance

The promise is simple: dependable work, competitive pricing, and fast communication from the first request through completion.
